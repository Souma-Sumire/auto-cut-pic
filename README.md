# AutoCutPic

专为照片冲印场景设计的高性能桌面批量照片裁切工具。支持多核并行处理、工业冲印 300 DPI 精度换算、单张精修工作台与批量画廊双重视图，自适应多种常用相纸尺寸。

---

## 运行环境

- 操作系统：Windows 10 / 11 (x64)
- 运行依赖：[.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)

---

## 功能特性

- **冲印规格与画幅自适应**：预设 3寸、5寸、6寸（默认）、7寸、8寸等工业冲印相纸规格，严格按 300 DPI 换算像素；根据照片物理长宽比自动匹配横向或纵向构图。
- **单图独立构图与模式**：
  - **裁剪填充 (Fill)**：按相纸画幅填满，超出区域暗化半透明遮罩呈现，支持自由平移构图。
  - **留白完整 (Fit)**：纯白相纸底板立体投影，保留完整画面与白边。
  - 构图模式与平移偏移量属于单张照片独立保存，自由混合搭配，互不干扰。
- **双重视图自由切换**：支持在“单张工作台”与“批量画廊”间无缝切换，画廊中实时显示每张照片的实际裁切线与留白边界。
- **专业取景框拖拽交互**：支持直接使用鼠标拖拽裁切框边框或手柄调整构图，并搭配键盘进行像素级微调。
- **多核并发极速导出**：充分利用多核性能并行处理，一键导出至原图同级目录下的 `Clipped_Photos` 文件夹，输出过程中支持实时查看进度与随时中止。

## 使用指南

1. **导入照片**：将照片或整个文件夹拖入界面（支持自动递归扫描子文件夹），也可点击“导入照片文件夹”或“添加照片文件”。
2. **选择冲印相纸**：在右侧面板选择目标冲印相纸规格（如常用 6寸）。
3. **调整构图与裁切模式**：
   - 使用鼠标按住裁切框边框或中心手柄拖动，或者使用 `WASD` / 方向键微调构图。
   - 按 `F` 键为当前选中照片切换“裁剪填充”或“留白完整”模式。
   - 按 `Q` / `E` 快速切换上一张 / 下一张照片。
   - 按 `G` 键切换至画廊视图，快速巡检所有照片的构图与裁切效果。
4. **批量导出**：确认构图无误后，点击界面右侧“开始批量导出”按钮完成输出。

## 快捷键指南

| 快捷键 / 操作 | 功能说明 |
| :--- | :--- |
| **鼠标左键按住拖拽** | 拖动裁切框边框或手柄平移构图 |
| `W` / `A` / `S` / `D` 或 `方向键` | 1% 步进微调构图偏移 |
| `Shift + WASD` 或 `Shift + 方向键` | 10% 步进快速移动构图 |
| `Ctrl + WASD` 或 `Ctrl + 方向键` | 构图瞬间向对应边缘贴边对齐 |
| `Q` / `E` | 切换上一张 / 下一张照片 |
| `F` | 切换当前照片模式（裁剪填充 / 留白完整） |
| `G` | 切换视图模式（单张工作台 / 批量画廊） |

> 为防止误操作批量覆盖磁盘文件，导出仅能通过点击界面“开始批量导出”按钮触发，不设快捷键。

## 构建与开发

本地开发与编译需安装 [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。在项目根目录下执行：

```powershell
# 本地直接运行
dotnet run

# 运行自动化单元测试
dotnet test

# 编译并发布独立单文件可执行程序 (Win-x64)
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```
