# AutoCutPic

桌面批量照片裁切与冲印构图工具。面向照片冲印、相册制作场景，提供 300 DPI 精度换算、智能免修识别、后台安全预导出与键盘优先的高效操作流。

## 下载与运行

- **操作系统**：Windows 10 / 11 (x64)
- **免安装运行**：前往 [Releases](https://github.com/Souma-Sumire/auto-cut-pic/releases) 下载最新的 `AutoCutPic-win-x64.zip`，解压即可运行，无需额外配置环境。

## 核心特性

- **冲印规格与方向自适应**：预设 3寸、5寸、6寸、7寸、8寸等标准规格（300 DPI 物理基准）；自动识别并剔除长边黑白边框，自适应横纵相纸方向。
- **免修照片识别与过滤**：比例与相纸契合（裁切损耗 < 1.5%）的照片自动识别为免修，提供全部显示、淡化免修与隐藏免修三种视图，切图自动跳过无需裁切的照片。
- **单图独立构图**：单张照片独立保存裁剪填充（Fill）或留白完整（Fit）模式。留白模式支持自由缩放与平移，自定义白边排版。
- **后台流水线预导出**：裁切后续照片时，后台静默预渲染已定稿照片（5 秒安全期防反悔）；最终批量导出时秒级复用缓存。
- **工程自动保存**：工作区进度定时平缓落盘至系统临时目录，关闭与重启无缝恢复，支持 `Ctrl+S` 手动归档。

## 快捷键

| 操作 | 功能说明 |
| :--- | :--- |
| **鼠标拖拽 / 四角折角手柄** | 调整裁切框构图位置与缩放比例 |
| `W` / `A` / `S` / `D` 或 `方向键` | 微调构图（`Shift` 10倍步进，`Ctrl` 贴边对齐） |
| `Q` / `E` | 上一张 / 下一张照片（自动跳过免修项） |
| `F` / `空格` | 切换当前照片模式（裁剪填充 / 留白完整） |
| `X` | 翻转相纸方向（横向 / 纵向） |
| `R` | 恢复当前照片默认剪切构图（偏移与缩放重置） |
| `Ctrl + 滚轮` / `Ctrl + 0` | 无级缩放平铺缩略图卡片 / 恢复默认大小 |
| `Ctrl + A` | 全选当前照片列表 |
| `Ctrl + S` / `Ctrl + O` | 保存工程 / 打开工程文件 |
| **鼠标中键按下** | 启用 Windows 经典自动平滑滚动模式 |

> 注：导出涉及批量磁盘写操作，不设快捷键，仅能通过点击界面“开始批量导出”按钮触发。

## 本地构建

需安装 [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)：

```powershell
# 运行
dotnet run

# 运行单元测试
dotnet test

# 打包发布独立单文件程序 (win-x64)
dotnet publish AutoCutPic.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish/
```
